# Port & Process Killer (GNOME Shell Extension)

GNOME Shell extension per monitorimin ne kohe reale te portave lokale TCP (`ss -tE`) dhe menaxhimin e sherbimeve/proceseve aktive nga Top Bar.

## Instalimi

```bash
git clone https://github.com/a1d-latifaj/gnome-port-killer.git
cd gnome-port-killer
./install.sh
```

Pastaj bej **Log Out / Log In** dhe aktivizoje:

```bash
gnome-extensions enable port-killer@dev
```

## Cinstalimi

```bash
./uninstall.sh
```
